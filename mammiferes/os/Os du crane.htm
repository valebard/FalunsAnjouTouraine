Le rocher...devenu pierre.

Le rocher est une cavité osseuse qui accueille les structures cachées de l’oreille. Dans certains cas, cet os est solidaire de l’os temporal, dans d’autres cas il y est seulement juxtaposé. D’aspect triangulaire, il est appliqué sur la partie interne inférieure de l’os temporal.

L'oreille moyenne est placée dans la portion plus superficielle de cet os. On y rencontre les 3 osselets, marteau enclume et étrier qui trouvent leurs accrochages sur le rocher.
Les structures de l'oreille interne sont contenues dans la profondeur des cavités du rocher. Le fond du rocher est perforé de manière à communiquer avec l’intérieur de la boite crânienne par le moyen de nerfs. Il est possible de retrouver sur les fossiles ces conduits qui perforent l’os.

Le fait de s’appeler le rocher est précisément dû au caractère très résistant de cet os. C’est cette propriété qui permet à cet os de fossiliser facilement.

Bulle tympanique


Il s'agit d'une petite structure osseuse située sous le crâne mais reliée à celui-ci. Les bulles tympaniques d'artiodactyles sont assez compressée.
